# The Cure: Public Downloads

Official public desktop downloads for **The Cure**, an independent survival-horror game.

Download the latest builds from [Releases](https://github.com/zacbeavers7-source/the-cure-downloads/releases/tag/desktop-latest) or visit [The Cure website](https://the-cure-3eo.pages.dev).

This repository contains **release downloads only**. The Godot source code and development repository are private.

**Early access:** Builds may contain bugs. On macOS, unsigned builds may require approval in System Settings > Privacy & Security.
